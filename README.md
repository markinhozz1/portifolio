# Portfólio — Marcos André

Site estático para apresentar landing pages feitas para negócios locais.

Os projetos listados são **demonstrações e projetos conceito**. Não são sites oficiais e não representam clientes contratados.

## Como ver localmente

Abra `index.html` no navegador ou sirva a pasta:

```bash
python3 -m http.server 8080
```

## Conteúdo

- `index.html`, `styles.css`, `script.js`, `favicon.svg`, `robots.txt`
- `fonts/` — Instrument Sans e Instrument Serif (licença SIL OFL)
- `img/` — capturas dos projetos, versões otimizadas para os cards e a imagem de prévia social
